# RFC Index

Enhancer uses RFC-style documents for major design areas.

RFCs preserve long-term architecture intent and make references stable across ChatGPT, Codex, Claude, Gemini, and future Enhancer agents.

## Status Values

- `Draft`: proposed design, not implemented.
- `Accepted`: approved design direction.
- `Implemented`: verified in code and tests.
- `Superseded`: replaced by a newer RFC.

## Rule

Major architecture changes should update or add an RFC and record the accepted decision in `DECISION_LOG.md`.
